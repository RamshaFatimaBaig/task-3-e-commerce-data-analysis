Brazilian E-Commerce SQL Data Analysis
Project Overview

This project performs SQL-based data analysis on the Brazilian E-Commerce Public Dataset (Olist) using PostgreSQL and pgAdmin 4.

Tools Used
PostgreSQL
pgAdmin 4
SQL
GitHub
Dataset

The project uses the Brazilian E-Commerce Public Dataset (Olist), containing information about orders, customers, products, sellers, payments, reviews, and order items.

SQL Analysis Performed

The project demonstrates:

SELECT and WHERE
ORDER BY
GROUP BY and COUNT
Aggregate functions such as SUM and AVG
INNER JOIN
LEFT JOIN
RIGHT JOIN
Subqueries
SQL Views
Indexes for query optimization
Revenue analysis by payment type
Files
ecommerce_analysis.sql — SQL queries used for the analysis
dataset/ — CSV files used for the project
Outcome

The project demonstrates how SQL can be used to retrieve, analyze, and manipulate structured e-commerce data using PostgreSQL.
